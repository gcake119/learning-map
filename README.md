# learning-map

## 中文

`learning-map` 是一套用來製作**互動式學習簡報**的通用 Skill。

它不限定技術、AI 或 System Design。可以用於任何適合透過互動、圖解、比較、模擬、逐步揭露或操作來理解的主題，例如：

- 技術與工程
- 科學
- 歷史與人文
- 語言學習
- 專業訓練
- 流程與制度
- 概念模型
- 數量與因果關係

核心原則是：**先決定學習者需要理解什麼，再選擇最適合呈現這個概念的互動方式。**

不要求每份教材使用相同版型，也不要求使用系統圖、流程模擬器或任何特定元件。

主要 Skill 規格：

- `SKILL.md`

第一個已完成 UI 驗收的 reference implementation：

- Repository：`gcake119/agent-system-design-learning-map`
- Route：`#/deck/token-profiler`

這個 reference 用來示範已驗證的互動節奏與 presentation-first 呈現方式，不代表未來教材都要製作 Agent、Token Profiler 或 System Design 內容。

## English

`learning-map` is a general-purpose skill for creating **interactive learning decks**.

It is not limited to technical subjects, AI, or System Design. It can be used for any topic that benefits from interaction, diagrams, comparison, simulation, progressive disclosure, or direct manipulation, including:

- technology and engineering
- science
- history and humanities
- language learning
- professional training
- processes and institutions
- conceptual models
- quantitative and causal relationships

The core principle is: **first identify what the learner needs to understand, then choose the interaction that best makes that concept visible and learnable.**

The skill does not require every deck to use the same layout, system diagrams, flow simulators, or any specific component.

Main skill specification:

- `SKILL.md`

First UI-validated reference implementation:

- Repository: `gcake119/agent-system-design-learning-map`
- Route: `#/deck/token-profiler`

The reference demonstrates a validated interaction rhythm and presentation-first experience. It does not imply that future decks must teach Agents, token profiling, or System Design.
